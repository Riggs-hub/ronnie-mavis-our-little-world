RONNIE & MAVIS — OUR LITTLE WORLD (FINAL VERSION)

Keep every file in this folder together. Open index.html in a modern browser.

Tap START OUR STORY to begin. The Perfect Match song starts from that tap and loops while you explore. If your browser blocks audio, tap the page once more.

Use the on-screen joystick to move Ronnie. Get close to each glowing heart and tap OPEN NEARBY MEMORY. The first WhatsApp memory uses the clearer replacement screenshot and scrolls automatically; you can also swipe it manually.

After all five memories, Ronnie's special message appears with Mavis's pink-outfit photo. Tap PLAY OUR STORY AGAIN to replay the whole game. The game is designed for a phone-sized portrait screen.

For sharing with Mavis over the internet, upload the extracted folder to a static website host (all files must remain together). The ZIP download itself can be sent as an attachment, but it is not a public web page link.
